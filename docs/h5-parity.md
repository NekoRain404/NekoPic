## 明确不对齐的部分

- H5 的高级调色参数当前只存 UI；原生版要求真实像素与撤销。
- H5 的滤镜缩略图是示例照片 + CSS 效果；原生版使用当前照片异步渲染。
- H5 的浏览器 IndexedDB 自动恢复不等同原生崩溃恢复，也不能当备份。
- 原生版不承诺 H5 的浏览器文件覆盖语义；保存使用系统文件对话框与原子写入。
