# ADR-0001：分层模块与依赖方向

状态：已采纳（2026-11-05）

## 背景

当前 `documentcontroller.cpp`、`Main.qml` 承担了较多职责，新增能力（文字、形状、恢复、导出选项）若继续堆入会形成单点耦合，阻碍并行开发。

## 决策

采用 `core → io/render → document → app → QML` 的单向依赖分层：

- `core`：纯图像算法，只依赖 Qt Core/Gui 值类型。
- `io`：编解码、格式能力、元数据；可选 Rust 提供者。
- `render`：预览后端、GPU 能力探测、CPU/GPU 一致性。
- `document`：文档状态、命令事务、撤销历史、未来对象模型。
- `app`：QML 桥接控制器与入口。
- QML：只读状态、发命令。

依赖只能向下；禁止 `core` 引用 QML、`document` 引用控件、QML 直接操作像素。

## 后果

- 正面：可并行开发、可单测、可替换服务、升级空间明确。
- 代价：需要逐步从现有控制器提取历史/命令，短期增加迁移工作。
- 约束：公共接口（控制器属性/命令、CMake、翻译）由集成负责人统一修改。
