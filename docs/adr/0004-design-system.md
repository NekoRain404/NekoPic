# ADR-0004：单一设计系统与动效语言

状态：已采纳（2026-11-05）

## 背景

现有 QML 在组件内重复定义颜色、间距、圆角与动画，主题与视觉一致性难以保证，也不利于并行开发。

## 决策

- `qml/UI/Theme.qml` 单例提供语义颜色、间距、圆角、阴影、字号与层级。
- `qml/UI/Motion.qml` 单例提供时长、缓动、弹簧参数与「减少动效」开关。
- 通用控件集中在 `qml/UI`：按钮、图标按钮、工具按钮、分段控件、滑杆、面板、卡片、对话框、滚动条等。
- 组件不得内联颜色/时长魔法值；特殊品牌值必须命名为令牌。
- 动效原则：120–280ms、缓出为主、按压 0.98、悬停轻提亮、状态切换不弹跳；尊重系统减少动效。
- 可访问性：每个自定义控件提供 `Accessible.name/role`、可见焦点环、键盘操作与禁用态。

## 后果

- 正面：主题切换、视觉升级、并行 UI 开发只改令牌或组件。
- 代价：首轮需要迁移现有 `Main.qml`/面板的硬编码值。
- 约束：H5 只作视觉参考，不逐像素复刻；原生控件遵循桌面键盘与可访问性习惯。
