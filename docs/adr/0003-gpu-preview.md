# ADR-0003：GPU 交互预览，CPU 权威提交

状态：已采纳（2026-11-05）

## 背景

拖动调色滑杆时，当前实现每次参数变化都排队 CPU worker，大图上反馈受线程调度与内存拷贝限制。Qt Quick 已由 RHI 硬件加速显示，可在 GPU 上即时预览。

## 决策

- 交互期间：以**底图**（未应用调色/滤镜）为基础，用着色器按待提交参数即时渲染；不触发 CPU 预览 worker。
- 松手后：CPU 生成权威像素，提交撤销历史，替换预览。
- 启用条件：非软件渲染后端、着色器可用、无滤镜叠加（滤镜会先落到 `image_`，底图不含滤镜）。否则回退现有 CPU 预览。
- 着色器与 `core/adjustments` 使用同一公式；提供 CPU 镜像实现与容差测试。
- 导出与保存永远使用 CPU 结果。

## 后果

- 正面：拖动反馈与界面同帧率，减少后台任务与内存峰值。
- 代价：需要维护着色器/CPU 两套公式与一致性测试。
- 风险：不同 RHI 后端（OpenGL/Vulkan/Metal/D3D）行为差异；以能力探测和真实设备抽查控制。
