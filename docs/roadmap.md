# NekoPic 路线图

本文件是方向与并行边界，不是排期承诺。每阶段结束以测试与真实设备抽查为准。

## 阶段 0：交接基线（已完成）

- 完整保存工作目录与未跟踪源码；C++ 6/6、QML 62 passed。

## 阶段 1：架构地基（当前）

目标：让后续功能可以并行、可测、可回退。

- [x] 分层目录与依赖规则落地（`core/io/document/render/platform/app`）。
- [x] `FormatRegistry` 能力注册表，文件对话框与导出格式由能力驱动。
- [x] 设计系统：`Theme` / `Motion` 单例 + 通用控件 + 组件测试（已接入主界面/Inspector/裁剪/打码）。
- [x] GPU 交互预览：着色器、CPU 镜像、能力探测、自动回退（OpenGL RHI 实测一致）。
- [x] Rust 评估：基准完成，结论为暂不引入，见 ADR-0002 与 `native/rust/BENCHMARKS.md`。
- [x] CMake 模块化、可选特性开关、CI 校验脚本与 ASan/UBSan 脚本。
- [ ] 真实显示器视觉抽查与流畅度记录（已完成离屏/OpenGL RHI 截图与 QML 测试，待真实屏幕与多后端复核）。

### 阶段 1 附带落地

- 命令行打开图片、最近文件、复制到剪贴板。
- 图片尺寸 / 画布尺寸后端（含撤销与测试），界面待阶段 2 接入。
- 语言切换数据化与持久化；导出格式由实际编解码器驱动。

## 阶段 2：常用编辑闭环

- 对象系统（文字、形状、普通画笔）与命令事务；旋转/裁剪/缩放的坐标契约。
- 吸管、取色放大镜、剪贴板、最近文件、命令行打开。
- 图片尺寸与画布尺寸扩展分离。
- 文字工具：多行、对齐、描边、Linux 中文字体回退。

## 阶段 3：质量与格式

- ICC/EXIF 策略、输出选项（质量、背景、元数据）、格式能力矩阵。
- 崩溃恢复快照（带版本与完整性检查，明确非工程格式）。
- 大图预算、任务取消、内存调度；CPU/GPU 一致性回归。
- 可选扩展格式与 Rust 模块（若达到 ADR-0002 门槛）。

## 阶段 4：平台与发布

- 打包、桌面关联、发布 CI、升级机制。
- 多语言完整性、主题可访问性、触控笔/高 DPI 验证。
- 性能基准与回归门禁。

## 并行工作流

| 工作流 | 所有权 | 交付 |
| --- | --- | --- |
| UI | `qml/UI/**`、组件测试 | 令牌、控件、动效、主题 |
| 渲染 | `src/render/**`、`shaders/**` | GPU 预览、能力探测、一致性测试 |
| 格式/Rust | `src/io/**`、`rust/**` | 能力注册表、可选提供者、基准 |
| 文档模型 | `src/document/**` | 历史/命令/对象模型提取 |
| 集成 | CMake、`main.cpp`、`Main.qml`、翻译 | 接线、构建、测试、验收 |

跨工作流变更：先由集成负责人落地公共接口，再并行实现；禁止同时改同一核心文件。
