# 工具交互契约（文字 / 形状 / 画笔 / 选择）

状态：文字工具与模糊打码已实现（放置/字号/颜色/对齐/撤销/保存合成；马赛克+模糊画笔/矩形）；形状、普通画笔与选择工具按本文推进。对象内核与控制器接入见 `object-model.md`。

## 通用规则

- 所有工具坐标使用文档图像像素；QML overlay 负责显示坐标映射，沿用 Crop/Mosaic/Eyedropper overlay 的模式。
- 一次放置、一次拖动、一笔绘制、一次文字编辑各形成一次撤销事务；预览帧不单独入栈。
- 工具激活时隐藏无关面板；Esc 取消当前手势/退出工具，Enter 确认。
- 忙碌、未打开图片、只读状态禁用工具并给出可理解提示。
- 工具不得直接改像素或对象；通过 DocumentController 的公开命令。
- 选中态属于 UI；删除/移动/改属性是命令。

## 文字

流程：

1. 选择文字工具，画布进入放置模式（`TextPlacementOverlay`）。
2. 单击画布取得锚点（图像像素），打开 `TextDialog`。
3. 输入多行文本、字号、颜色、对齐（9 向锚点/对齐），确认后调用 `addText`。
4. 对象进入图层，可再次点选/移动/删除；未来支持双击进入编辑。

契约：

- `addText(text, anchorX, anchorY, fontSize, color, alignment)`：锚点决定文本框哪个位置落在该点；空白文本拒绝；字号 4–512。
- 文本对象使用矢量轮廓渲染，不烘焙像素；裁剪/旋转/缩放随图像变换。
- CJK 依赖系统字体回退，发布前需验证常见发行版；无自动换行（后续可加固定宽度）。
- 编辑已有文本时，撤销粒度是整段编辑，不是每个字符。

## 形状

流程：

1. 选择形状类型（矩形/椭圆/直线/箭头/多边形）。
2. 拖拽创建；Shift 约束等比/45°；释放提交一个对象。
3. 属性面板调整填充、描边、线宽、圆角；移动/缩放/删除。

契约：

- 几何使用 `ShapeObject`/`ShapeGeometry`；拖拽锚点与当前点由 UI 传入，约束函数复用内核。
- 多边形逐点添加，双击/Enter 闭合；Esc 取消未提交形状。
- 旋转/翻转/裁剪/缩放规则与文字一致。

## 画笔

流程：

1. 选择画笔，设置直径、颜色、硬度（未来）、间距（未来）。
2. 拖动采样点；显示笔刷光标与半透明预览；释放提交一个 `StrokeObject`。
3. 一笔一个撤销项；Esc 取消未提交笔迹。

契约：

- 采样点裁剪到图像；最多 4096 点，超出时简化或分段并提示。
- 压力/倾斜设备后续接入；鼠标路径使用防抖/平滑。
- 画笔对象与马赛克不同：马赛克修改底图像素，画笔是可编辑对象。

## 选择与移动

- 点选最上层可见且未锁定对象；Shift 多选；空白处取消选择。
- 拖动移动选中对象；方向键微调（Shift 10 px）。
- 删除键删除；层叠顺序命令（前移/后移/置顶/置底）。
- 选中框/手柄是 UI overlay，不写入文档历史；变换提交时才形成命令。

## 与像素操作的关系

- 调色/滤镜在马赛克底图之上、对象之下：`base → adjustments/filters → objects → display/export`。
- 马赛克/模糊写入底图；对象保持在上层。
- 保存/导出始终使用合成结果；重新打开合并图后对象不可编辑，界面必须提示。

## 验收样例

- 添加文字后拖动/旋转/裁剪/缩放，对象位置与像素一致，撤销逐步恢复。
- 文字包含中文且字体回退正确；空白文本不创建对象。
- 一笔画笔只产生一个撤销项，Esc 取消不污染历史。
- Shift 绘制正方形/正圆/45° 直线；多边形闭合正确。
- 选中被锁定/隐藏对象时命中测试跳过。
