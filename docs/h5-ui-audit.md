# H5 与原生 UI / 功能审计

审计日期：2026-11-05。对照根目录 H5 页面（`index.html`，Chrome 1440×900 实际截图）与原生 Qt 界面（`nekopic assets/demo.jpg`）。
结论：**核心编辑闭环已对齐，但功能未全部完成；UI 结构一致，视觉与部分交互仍有可见差异。**

## 1. 已对齐的核心功能

打开/最近/拖放/命令行、缩放/平移/适应、旋转/翻转、裁剪、图片尺寸/画布尺寸、撤销/重做、
基础调色、HSL 八色、RGB/R/G/B 曲线、色彩分级、细节/效果、自动增强、直方图、
12 款滤镜 + 分类/搜索/收藏、画笔、文字（H5 式右侧面板 + 二次编辑）、形状（含多边形）、
马赛克/模糊、吸管与放大镜、对象选择/多选/图层/对齐、对比原图、PNG/JPEG/WebP/TIFF/AVIF/JXL 导出、
质量与 JPEG 背景、复制结果、快捷键说明、深浅/跟随系统主题、中英双语、设置页。

## 2. H5 有、原生尚未完全对齐

| 项目 | H5 | 原生当前 | 影响 |
| --- | --- | --- | --- |
| 前景色 | 左下角共享前景色块，画笔/文字/形状共用 | 各面板独立颜色 | 工作流差异明显 |
| 画笔细节 | 大小 + 不透明度，软边圆头 | 直径 + 颜色，硬边 | 绘制手感差异 |
| 自动恢复 | IndexedDB 临时恢复 + 状态提示 | 版本化 PNG 快照 + 启动恢复对话框；快照为扁平化结果 | 核心目标对齐；对象不可再编辑（首版限制） |
| 顶部工具入口 | 变换、画布按钮；边框、历史工具 | 画布在菜单/对话框；变换仅旋转翻转；无边框/历史入口 | 入口与布局不同 |
| 底部状态 | 对象数量、sRGB、缩放滑杆、恢复状态 | 尺寸、状态文字、± 缩放按钮 | 信息与控件不同 |
| 导出文件名 | 导出对话框内可编辑名称 | 名称只读，名称在另存对话框选择 | 小流程差异 |
| 面板密度 | 5 页签两行、面板更宽 | 5 页签一行、292 px | 视觉紧凑度不同 |
| 画布叠加信息 | 摄影师/提示文案、底部快捷提示 | 仅工具提示 | 展示差异 |

说明：H5 的「变换 / 画布 / 边框 / 历史」中，前两者是无处理逻辑的入口，后两者在 `app.js` 没有面板实现；原生将这些能力放进了菜单/对话框或直接实现，不能简单按“H5 有原生没有”计数。

## 3. 原生已超出 H5 的部分

- 高级调色真正写像素（H5 明确标注为 UI 演示）。
- 滤镜缩略图来自当前照片（H5 是示例图 + CSS）。
- 对象多选、图层面板、六向对齐、可见/锁定、层叠顺序。
- GPU 调色预览、调色 CPU 优化、真实撤销事务。
- 更广导出格式、质量/背景选项、命令面板、设置页、完整双语。
- 真实马赛克 + 模糊、吸取放大镜、拖放打开、最近文件。

## 4. 实际 UI 差异（可见）

| 区域 | H5 | 原生 |
| --- | --- | --- |
| 顶部操作栏 | 打开/撤销/重做/旋转/裁剪/变换/画布 + 查找、对比、保存、另存为下拉 | 打开/撤销/重做/旋转/裁剪 + 设置、搜索、保存、另存为 |
| 左侧工具列 | 选择/平移/调色/滤镜/画笔/文字/形状/打码/裁剪/取色 + 边框/历史 + 前景色 | 选择/平移/调色/滤镜/画笔/文字/形状/打码/取色/裁剪，无边框/历史/前景色 |
| 右侧面板 | 两行五页签，宽度更大，顶部有对比/更多工具 | 一行五页签，292 px |
| 底部栏 | 对象数、sRGB、缩放滑杆、恢复状态、快捷键 | 尺寸、状态文字、−/+/100%/适应 |
| 菜单 | 自定义 H5 菜单 | 原生菜单栏（含设置、帮助） |
| 视觉语言 | 石墨底 + 暖桃强调、较大留白 | 同一色系，但更紧凑的桌面密度 |

两张对照截图：`/tmp/h5-home.png`、`/tmp/nekopic-final2.png`（本机）。

## 5. 建议下一步（按收益排序）

1. 共享前景色：统一画笔/文字/形状颜色，增加左下角色块。
2. 画笔不透明度 + 软边/硬度。
3. 顶部「变换 / 画布」入口与 H5 对齐；边框/历史入口按实际功能决定是否加入。
4. 底部对象数量、sRGB 标识、缩放滑杆。
5. 调色面板两行页签/宽度对齐 H5。
6. 导出对话框可编辑文件名。

## 6. 实施进展（2026-11-05）

已补齐：

- 共享前景色：左下角色块，画笔/文字/形状描边共用，面板取色回写。
- 画笔不透明度与柔边：0–100% 不透明度写入墨迹 alpha；柔边由 `StrokeObject` 的径向渐变/多层同心描边实现（近似，不是高斯模糊）。
- 底部状态栏：尺寸、sRGB、对象数、缩放滑杆、−/+、100%、适应。
- Inspector：320 px、五页签两行（3 + 2）。
- 顶栏“变换”（旋转/翻转菜单）与“画布”入口。
- 导出对话框文件名可编辑并校验扩展名；目标文件夹仍由 Save As 决定。
- 崩溃/异常退出恢复：`RecoveryStore` 在文档变脏后防抖写入
  `AppLocalDataLocation/recovery/`，PNG 编码走 QtConcurrent；清单含 schema 版本、
  源文件名/路径、时间、尺寸、应用版本、`flattened` 与 SHA-256。启动时校验清单、
  PNG 头、尺寸和哈希，损坏则静默清理；恢复对话框提供 Restore/Discard。恢复后的文档
  命名为“Recovered session”、无保存路径（必须先 Save As），不会覆盖原文件。
  干净保存、回到保存点、正常退出且无未保存更改时自动删除快照；显式放弃退出也会删除。

首版恢复限制：快照保存的是 `editor.image()` 的渲染结果，因此调整、滤镜、文字和形状
均已烘焙进像素，不能像 H5 一样恢复可编辑对象/历史；`flattened` 字段明确标记这一点。
恢复状态提示目前体现为启动对话框，尚未在底部状态栏常驻显示。

仍未对齐/保留差异：

- H5 的“边框/历史”工具入口仍未加入；H5 本身没有对应面板逻辑。
- 画布内摄影师/提示文案未复刻，原生以工具提示和状态消息替代。
- 共享前景色不覆盖形状填充；画笔预览与提交笔画的亮度仍有轻微差异。
- 恢复快照为扁平化图像，不保留对象可编辑性（见上）。
- 1100×720 已通过几何测试，视觉截图仍以 1440×900 为主。

## 7. 2026-11-05 交互与设置页修复

- **对象拖动改为像素级实时预览**：拖动开始时控制器生成两张文档分辨率裁片
  （去掉选中对象的底图 + 仅含选中对象的透明层），QML 只平移对象裁片，松手后
  仍调用一次 `moveObjects()` 提交，因此拖动跟手且只产生一步撤销。选区框同步移动，
  多选和高级调色底图都适用。
- **图层面板修复**：`DocumentController::objectSummaries()` 的 `QVariantList` 在
  QML 中是类数组对象，`Array.isArray()` 为 false，导致面板一直显示 0。面板现在
  接受带 `length` 的列表，真实对象可见、可选中、可对齐/排序/删除。
- **右侧面板滚动条移除**：调色、选择、文字、画笔、形状、滤镜面板不再显示可见
  滚动条，滚轮/触控滚动保留。
- **设置页升级**：偏好设置从单列小弹窗改为 820×640 双栏页面，分类为外观、编辑、
  导出、语言、恢复与安全、关于；内容区固定头部/底部、隐藏滚动条、键盘可导航。
  新增 `recoveryEnabled`（自动恢复快照开关）与 `startupTool`（下次打开图片的
  起始工具）；恢复与安全页可查看/清除现有快照，关于页显示版本、格式能力与快捷键
  入口。顶栏“设置”和“视图 → 偏好设置”均可打开。
- 限制：恢复快照仍是扁平化图像；`startupTool` 只影响下一次打开图片；设置页标签
  继续使用现有 `_tr()` 内联中英文本，未新增 `.ts` 条目。
