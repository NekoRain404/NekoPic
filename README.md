## 原生开发版

原生 Qt Quick / C++20 首阶段位于 [`native/`](native/)，原有 HTML 原型保留。需要 Qt 6.5 以上的 Core、Gui、Quick、Quick Controls、Concurrent 和 Qt Linguist 工具，以及 CMake 和 C++20 编译器；运行 C++ 测试还需要 Qt Test。

```sh
cmake -S native -B native/build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build native/build
ctest --test-dir native/build --output-on-failure
./native/build/nekopic
./native/build/nekopic photo.jpg
```

开发/视觉回归可加 `--screenshot /tmp/ui.png`，程序会在文档空闲后抓取窗口并退出；`--tool filters` / `--tool brush` 可直接打开某个工具，`--settings` 直接打开设置页。

目前支持后台打开 Qt 解码器能识别且符合资源限制的图片、命令行打开、最近文件、适应窗口 / 100% 查看、滚轮缩放、中键平移、90 度旋转、翻转、曝光 / 亮度 / 对比度 / 饱和度调整（GPU 后端可用时拖动走着色器即时预览，CPU 结果为准）、撤销 / 重做、复制结果到剪贴板，以及按实际编解码器能力保存或另存 PNG / JPEG / WebP / TIFF / AVIF / JPEG XL 等格式。调色参数保留在滑杆中，反复修改基于底图重新计算；一次滑杆操作形成一步撤销。

调色覆盖五个页签：基础（曝光/亮度/对比度/高光/阴影/白色色阶/黑色色阶/色温/色调/饱和/自然饱和度）、HSL 八色、RGB/R/G/B 五控制点曲线、阴影/中间调/高光色彩分级，以及纹理/清晰度/去雾/锐化/降噪/暗角/羽化/颗粒/褪色；另有采样直方图与一步撤销的自动优化。滤镜提供原图 + 12 款风格（自然/胶片/人像/氛围/黑白分类）、搜索、收藏与强度调节，缩略图来自当前照片的异步渲染。裁剪已接入自由 / 固定比例、拖动手柄、移动选区、重置和确认 / 取消。打码支持马赛克与模糊两种效果，均可用圆头画笔或矩形选择区域；画笔直径、色块大小与模糊强度分别设置，按图像像素计算；一笔或一次矩形拖动形成一步撤销，Esc 可取消未提交的操作。打码后仍保留调色与滤镜参数，旋转 / 翻转也会作用于打码结果。马赛克不能保证敏感信息无法推断，分享前请检查导出图片。

保存未修改的图片不会重新编码；另存为 JPEG 使用白色背景合成透明区域，可能有损。读写格式由运行环境中的 Qt 插件决定，界面只展示实际可用的导出格式；本机矩阵与导出策略见 [格式能力](docs/architecture/formats.md)。中文 / 英文切换、跟随系统/深浅主题与减少动效设置会保留；界面使用 `native/qml/UI` 设计系统。当前还支持 Ctrl+K 命令面板、吸管与取色放大镜、拖放打开、保存前询问、图片尺寸 / 画布尺寸对话框，以及导出质量与 JPEG 背景选项。对象模型已接入文档（文字 / 形状 / 笔迹、层级、命中测试、变换与裁剪）：文字工具采用 H5 的右侧属性面板：内容、字体、字号、左右/居中对齐、深色描边与颜色；点击画布放置，双击已有文字载入面板实时编辑，输入停顿或样式变化形成撤销步骤；普通画笔支持直径与颜色，一笔一撤销；形状支持矩形、椭圆、直线、箭头与多边形，带 Shift 约束；选择工具支持 Shift 多选、组拖动/删除、方向键微调，右侧图层面板可切换可见/锁定、调整层叠顺序并六向对齐。平移工具（H）支持左键拖动画布。设置页统一管理外观、减少动效、GPU 预览、导出质量/JPEG 背景、语言与关闭确认，可从工具栏「设置」或 Edit 菜单打开。调色与滤镜是两个独立工具/面板：调色只处理颜色参数，滤镜是独立预设库。QML 交互测试可运行：

```sh
QT_QPA_PLATFORM=offscreen /usr/lib/qt6/bin/qmltestrunner -input native/qml/tests
```

几何变换、调色、滤镜和打码在后台 CPU 运行，大图仍可能有较高内存开销；撤销历史预算为 256 MiB，单个快照超过预算时无法撤销。当前调色按编码值计算，尚非线性光或完整 ICC 色彩管理。多选/对齐/图层顺序、画笔硬度/间距/压感、EXIF 导出策略、完整 ICC 色彩管理、GPU 图像处理及崩溃恢复尚未完成。原生版仍在持续对齐 H5，不要将其用于不可替代的照片。架构和阶段说明见 [架构总览](docs/architecture/overview.md) 与 [路线图](docs/roadmap.md)，当前验收边界见 [开发交接文档](HANDOFF.md)。Rust 已完成基准评估，当前无优势模块，默认不参与构建；结论见 [ADR-0002](docs/adr/0002-rust-boundary.md) 与 [基准记录](native/rust/BENCHMARKS.md)。

## HTML 原型

以下内容描述的是浏览器原型，而非原生版。原型用于审阅 UI 与交互：工具切换、属性面板、菜单、对话框、主题和画布布局。已有编辑逻辑属于探索性演示，不代表正式功能完成或已满足全部编辑规则；图像处理与数据可靠性留待原生开发实现。

调色现分为基础、HSL、曲线、色彩分级、细节 / 效果五个页签。新增白黑色阶、色调、自然饱和度、八色 HSL、RGB 分通道控制点、阴影 / 中间调 / 高光着色、纹理、清晰度、去雾、锐化、降噪、暗角、羽化、颗粒与褪色。高级参数只展示交互，不改变像素，不进入撤销、导出或恢复记录；切换工具时保留当前会话中的参数。曲线支持拖动五个固定输入位置的控制点、数值滑杆及三个预设，目前为折线交互示意。双击新增滑杆恢复默认值，面板右上角重置全部调色。

滤镜扩展至 12 款风格加原图，提供自然 / 胶片 / 人像 / 氛围 / 黑白分类、搜索、会话内收藏、强度和移除滤镜。风格调用现有简化渲染参数，支持原图对比与撤销；缩略图使用示例照片和 CSS 风格示意，并非当前照片的精确渲染。尚未引入第三方滤镜库。开源库比较与原生接入建议见 [滤镜库选型](docs/filter-libraries.md)。

本轮交互扩展：打码先选画笔 / 矩形，再选马赛克 / 模糊；画笔可拖动显示半透明遮罩预览，大小、硬度和效果强度独立设置。顶部提供当前工具与快捷切换、画布和变换直达入口、Ctrl+K 功能搜索。补充边框样式、裁剪比例、笔刷细节与文字排版设置；这些新增参数只用于界面审阅，不承诺实际图像处理效果。

在此目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765 。无构建步骤、无运行时第三方依赖，示例照片已保存在本地。

浏览器原型用于审阅桌面布局和交互。界面覆盖打开图片、调色、滤镜、画笔、吸管、文字和形状、矩形马赛克/模糊、裁剪、旋转/翻转、图片尺寸和画布尺寸、撤销/重做、复制结果与 PNG/JPEG/WebP 输出流程。

保存使用浏览器文件系统接口（可用时）；不支持时下载合并后的图片，无法静默覆盖原文件。保存保留当前内存对象，关闭重开后是合并图。没有工程格式。

浏览器按自身 EXIF 方向与色彩解码能力加载图片，再渲染到 sRGB 画布。输出不复制原图 ICC 或 EXIF；导出窗口明确说明此限制。全链路 ICC、广色域显示和 EXIF 保留须在原生实现中验证。模糊/马赛克只改变导出像素，不保证敏感文字无法推断；需要彻底遮挡时使用不透明实色。

自动恢复使用本机 IndexedDB，浏览器清理存储后不可恢复；这不构成可靠备份。资源限额为 32 MP、单边 8192 px、80 条或约 128 MiB 的撤销记录、每笔最多 4096 个采样点。

示例照片：[Unsplash](https://unsplash.com/photos/aerial-photography-of-lake-surrounded-by-trees-and-mountains-during-daytime-jFCViYFYcus)，摄影师 Luca Bravo；下载来源为 Unsplash 图片服务。

原型未实现命令行关联、双语、专业笔刷间距/硬度设置、原生打印及压力设备兼容性验证。
